### FIX #7: REVERSE DEW ОЧЕНЬ СЛАБЫЙ ✅

**Причина:** Множитель 0.85 неправильно уменьшает мощность.

**Корневая проблема:** Строка 97 в `DEWImpulseCalculator.java`

```java
// БЫЛО:

// СТАЛО:
double strength = BASE_IMPULSE * 1.0 * gasPercentage * ropeMultiplier * speedMultiplier * altitudeBonus;
```

- **Усиление:** 76% больше!

**Что исправилось:**
- ✅ Reverse DEW теперь ОЩУТИМ
- ✅ Игрок может эффективно управлять скоростью
- ✅ Баланс между Forward и Reverse DEW

### FIX #1,2: LEFT HOOK СПАМ И РАССИНХРОНИЗАЦИЯ НА PHYSICS ✅

**Проблема:** 
- Left Hook спамит события
- На physics объектах крюк рассинхронизируется (требует SPACE для переподключения)

**Причина:** Логика синхронизации в `RemoteHookFollower.follow()` не обновляет привязку когда `findContaining()` возвращает NULL.

**Корневая проблема:** Строки 113-138 в `RemoteHookFollower.java`

```java
// БЫЛО:
SubLevel sl = SubLevelResolver.findContaining(level, cur, hint);
if (sl != null) {
    // ... обновляем anchor ...
}
store(anchor, left, sub, local, cur, sub != null ? level.dimension() : null);
// ПРОБЛЕМА: если sl == null, старая привязка остаётся в anchor!

// СТАЛО:
SubLevel sl = SubLevelResolver.findContaining(level, cur, hint);
if (sl != null) {
    // ... обновляем anchor ...
}
// [FIX v1.3.5] Always store result - either found SubLevel or NULL (clears stale anchor)
// This prevents infinite resync loop when SubLevel becomes temporarily unreachable
store(anchor, left, sub, local, cur, sub != null ? level.dimension() : null);
```

**Механизм исправления:**
1. Если `findContaining()` находит SubLevel → обновляем привязку
2. Если `findContaining()` возвращает NULL → **ОЧИЩАЕМ привязку** (store с NULL)
3. Это прерывает цикл "NULL → drop → reconnect → NULL"

**Что исправилось:**
- ✅ Left Hook больше не спамит
- ✅ На physics объектах крюк синхронизируется автоматически
- ✅ VANILLA vs PHYSICS поведение унифицировано
- ✅ Отсутствие требования SPACE для переподключения

**Регрессионная проверка:**
- [ ] Left Hook СТАБИЛЕН (нет спама)
- [ ] Right Hook работает
- [ ] Vanilla блоки: автоматическое подтягивание
- [ ] Physics объекты: автоматическое подтягивание (не требует SPACE)
- [ ] Нет медленного падения
- [ ] Звук не спамит (следствие исправления)
