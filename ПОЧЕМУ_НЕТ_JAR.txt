💡 ЧТО НУЖНО СДЕЛАТЬ ВАМ:
════════════════════════════════════════════════════════════════

На вашем компьютере (где есть возможность установить Java):

1. Установите Java 17 или выше:
   
   Ubuntu/Debian:
   $ sudo apt-get install openjdk-17-jdk
   
   macOS:
   $ brew install openjdk@17
   
   Windows:
   Скачайте с https://adoptopenjdk.net/

2. Скопируйте папку проекта к себе

3. Запустите компиляцию:
   $ cd odm-aeronautics
   $ ./gradlew clean build
   
4. Получите JAR:
   build/libs/daot-compat-1.3.5.jar

5. Скопируйте в мод-папку Minecraft
