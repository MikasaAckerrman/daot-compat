# Debug Logs

Folder for game logs and crash reports.

Upload your logs here for debugging.

## Files to upload:
- `latest_game.log` - Minecraft game log
- `sable-destructive-shutdown-*.log` - Sable crash logs
- `dpisok.txt` - List of installed mods
- Any other relevant error logs

## How to upload:
1. Go to GitHub web interface (see link below)
2. Click "Add file" → "Upload files"
3. Select and upload your log files
4. Commit with message describing the issue
