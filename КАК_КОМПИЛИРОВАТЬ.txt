🚀 КАК КОМПИЛИРОВАТЬ:
════════════════════════════════════════════════════════════════

ВАРИАНТ 1: Автоматический скрипт (самый простой)
────────────────────────────────────────────────────

1. Откройте терминал
2. Перейдите в папку проекта:
   $ cd /path/to/odm-aeronautics

3. Запустите скрипт:
   # На Linux/macOS:
   $ bash COMPILE_INSTRUCTIONS.sh
   
   # На Windows (в PowerShell):
   $ .\gradlew.bat clean build

4. Дождитесь завершения (2-5 минут)
5. JAR будет в: build/libs/daot-compat-*.jar


ВАРИАНТ 2: Ручная компиляция
────────────────────────────────

1. Проверьте Java:
   $ java -version
   (должна быть 17 или выше)

2. Перейдите в папку проекта:
   $ cd /path/to/odm-aeronautics

3. Скомпилируйте:
   # На Linux/macOS:
   $ ./gradlew clean build
   
   # На Windows:
   $ gradlew.bat clean build

4. Ждите завершения
5. Результат: build/libs/daot-compat-1.3.5.jar


❌ ЕСЛИ ОШИБКА "Java 11 is too old":
════════════════════════════════════════════════════════════════

РЕШЕНИЕ: Установите Java 17

Ubuntu/Debian:
  $ sudo apt-get update
  $ sudo apt-get install openjdk-17-jdk
  $ java -version  (проверьте версию)

macOS (с Homebrew):
  $ brew install openjdk@17
  $ /usr/local/opt/openjdk@17/bin/java -version

Windows:
  1. Перейдите на https://adoptopenjdk.net/
  2. Скачайте OpenJDK 17 LTS
  3. Установите
  4. Проверьте: java -version


✅ ЕСЛИ КОМПИЛЯЦИЯ УСПЕШНА:
════════════════════════════════════════════════════════════════

Вы получите файл:
  build/libs/daot-compat-1.3.5.jar

Копируйте его в папку модов:
  ~/.minecraft/mods/
  (или ваша папка Minecraft mods)

Требуемые модо-зависимости:
  ✅ Danny's AOT (любая версия)
  ✅ Create: Aeronautics (опционально)
  ✅ Minecraft 1.21.1+


📊 СТАТИСТИКА КОМПИЛЯЦИИ:
════════════════════════════════════════════════════════════════

Первый раз:      3-5 минут (загружаются зависимости)
Последующие разы: 30-60 секунд (кэш)

Размер JAR:      ~500 KB
Размер кэша:     ~1-2 GB


🎯 ПРОВЕРКА:
════════════════════════════════════════════════════════════════

1. Убедитесь что компиляция завершилась успешно:
   ✅ Должна быть строка "BUILD SUCCESSFUL"

2. Проверьте что JAR создан:
   $ ls -la build/libs/

3. Если ошибка:
   $ ./gradlew clean build --stacktrace
   (это даст подробный лог ошибки)


📞 ПОМОЩЬ:
════════════════════════════════════════════════════════════════

Если возникли проблемы:

1. Проверьте Java версию:
   $ java -version
   (должна быть 17 или выше)

2. Очистите кэш Gradle:
   $ ./gradlew --stop
   $ rm -rf .gradle build

3. Попробуйте снова:
   $ ./gradlew clean build --stacktrace

4. Если всё ещё не работает - скопируйте ошибку из лога
