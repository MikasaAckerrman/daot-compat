🚀 ЧТО ДАЛЬШЕ:
════════════════════════════════════════════════════════════════════════════

1. Обновить Java до версии 17+
   $ java --version
   (требуется 17+, текущая: 11)

2. Скомпилировать мод
   $ ./gradlew clean build
   (получится: build/libs/daot-compat-1.3.5.jar)

3. Протестировать в игре
   (инструкции в DEPLOYMENT_INSTRUCTIONS.md)
   • Проверить W (должно быть сильнее на 50%)
   • Проверить Reverse DEW (должно быть сильнее на 78%)
   • Проверить Rope Wrapping (тросы должны огибаться)
   • Проверить совместимость с Danny's AOT

4. Выложить в production
   • На GitHub
   • На CurseForge/Modrinth
   • Обновить версию
