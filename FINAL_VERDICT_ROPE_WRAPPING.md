## 🔴 НАЙДЕННЫЙ БАГ

### Описание

Двойная система обработки сегментов:

```
GrapplePhysicsController          SableRopeIntegration
(physics)                         (rendering)
     ↓                                ↓
segmentHandlers[1]            segmentHandlers[2]
     ↓                                ↓
Обновляется: ✅ каждый тик   Обновляется: ❌ никогда
Используется: физика          Используется: рисование
     ↓                                ↓
  РАЗНЫЕ ДАННЫЕ  ← ← ← СИНХРОНИЗАЦИЯ ОТСУТСТВУЕТ!
```

### Следствие

- ✅ **Физика:** Игрок ограничен на правильное расстояние (со сгибами)
- ❌ **Рисование:** Трос может рисоваться прямо (без сгибов) или fallback с сагом

### Баг в действии

```
Сценарий: Огибание столба

                      [СТОЛБ]
                        |
Hook ==================| Player
     (физически 10 м, вокруг столба)
     
Но визуально может быть:
Hook ===============\ Player
     (прямая 5 м сквозь столб)
```

**Добавить метод синхронизации:**

/**
 * Sync segment handler from physics system.
 * Called by GrapplePhysicsController after handler.update()
 */
public static void syncHandler(int hookId, RopeSegmentHandler handler) {
    segmentHandlers.put(hookId, handler);
}
